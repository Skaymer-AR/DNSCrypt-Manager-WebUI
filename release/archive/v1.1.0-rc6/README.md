# DNSCrypt Manager v1.1.0 RC6 — paquete histórico

Este prerelease conserva el ZIP original de RC6 y su SHA-256, recuperados del
archivo de pruebas del proyecto. El ZIP declara `version=v1.1.0-rc6` y
`versionCode=11006`; su checksum se verifica antes de publicarlo.

**Límite de procedencia:** no se conservó el commit fuente exacto usado para
generar RC6. Por eso la etiqueta Git apunta a la base fuente de la versión
estable `v1.1.0`; el ZIP adjunto sí es el artefacto original de RC6, pero no se
afirma que pueda reconstruirse bit a bit desde esa etiqueta.

Para instalar, se recomienda la release estable
[v1.1.0](https://github.com/Skaymer-AR/DNSCrypt-Manager-WebUI/releases/tag/v1.1.0), no esta
candidata histórica. IPv6 no fue validado exhaustivamente.
