# Preferencias de entrega del usuario

- Después de implementar cambios solicitados en la app Android, generar y entregar un APK instalable.
- Si los cambios también requieren actualizar el módulo root, generar y entregar su ZIP instalable junto con el APK.
- Cuando el usuario pida subir archivos a Google Drive, usar por defecto Mi unidad/codex. Los archivos de este proyecto se guardan en codex/DNSCrypt.
